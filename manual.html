0130 秒上手

这个页面的核心就一句话：链接是你的，数据存在你自己的浏览器里。没有账号、没有服务器，打开就能用。

  1. 第一次打开会带一批演示链接，随便改随便删。
  2. 中间那行工具条上点 ＋ 添加（在列表最前面），或者直接在链接区最左上那颗加号里填名字 + 网址。
  3. 整理的时候点工具条上的 编辑 进编辑模式：单击勾选、双击就地改名、按住拖动排序。
  4. 数据想带走或换电脑用：右栏底部 备份 / 恢复 → 导出 JSON。
一个小习惯建议：先把分类建好（比如「工作 / 设计 / 学习」），再往里丢链接 —— 比先塞几百条再回头分省事得多。

02界面长什么样

电脑上是铺满一屏的三栏；手机上自动收成单列，搜索条吸在顶部。屏幕底部正中还浮着一条标签栏（首页 / 导航 / 分享，还能自己加），三个页面就靠它切换（见 16 底部标签栏）。

左栏 · 门头标志（点图标改资料、点主标题打开链接）、分类导航（可以搬到这里竖排）、时钟与日期，最后一句可以点开改的问候语。
中栏 · 主战场搜索条、模式标签页（分类 / 全部 / 盲盒）、工具按钮、链接列表。
右栏 · 顺手用的最常访问、待办、本地音乐（一个能放歌的小盒子，歌都在自己电脑上），最底下一句可以点开改的文案，再配一排按钮（备份 / 外观 / 云同步 / 主题 / 快捷键 / 使用手册 / 分享页）——七颗长得一模一样，都是一颗带图标的胶囊。最后两颗是「去别处看看」：使用手册是就地打开这份手册（不会跳走再新开一页），分享页是切到「时光轨迹」那一整页（见 15 分享页）。按钮下面还有一小块快捷键提示。
手机上只剩中栏最重要的一条：吸顶搜索条 + 分类横滑 + 链接列表。门头（标志 + 主标题 + 副标题）搬到中栏最上面，时钟、日期和问候语挪到它右边（左边门头、右边时间，两栏占满整行，不浪费右半边的空白），右栏挪到列表之后；快捷键提示在手机上是收起来的（手机没有 ⌘K 和 Esc）。

分类栏可以换地方

工具条上那颗 位置：切到「左边」时分类会搬到左栏竖着排（两列小方块），适合分类多的人；切到「上边」时它横排在中栏顶部，适合分类少的人。这个选择会记住。

03链接：加 / 改 / 挪

加一条

  • 列表最前面那颗 ＋ 添加：填名字、网址、分类、标签（可选）。
  • 网址不写 https:// 也行，会自动补上。
  • 一长串直接粘进去：从别处复制来的「标题 + 网址」（比如 某某站点 https://example.com）粘到名字或网址任意一格里，它会自己拆成两个字段。拆得出来才动手 —— 只认恰好一个网址（粘一堆网址它不碰），而且另一格已经有内容就不覆盖，右下角会告诉你「没动它」。
  • 一次加很多条？用 导入，不要一条条点。

改一条

先在工具条上点 编辑 进编辑模式，然后：

  • 单击链接 = 勾选 / 取消勾选（不跳转，方便批量）。
  • 双击链接 = 就地改名字、网址、分类、标签。改完回车即存，Esc 取消。
  • 不在编辑模式时，单击就是打开链接（并且记一次访问，喂给「最常访问」）。

右键：一次能干的六件事

在一条链接上点右键：

打开 / 新标签打开跟单击一样，顺手一个入口
复制网址复制不到时会退成「摊开让你手抄」，不会静默失败
置顶到分类最前被置顶的链接永远排在这个分类最上面（手动排序时）
编辑等于双击
移到别的分类弹一个分类列表，点一下就搬走
删除会先弹一个确认框，点「确定」才删；删完右下角还会冒一个「撤销」，几秒内能反悔

右键不只认链接 —— 分类和固定栏上的胶囊也各自有自己的菜单，见下面两小节。

删除 / 清空：一律先问一声

凡是做完就回不去的动作，都会先弹一个确认框，告诉你「要没掉什么、怎么退回来」，点确定才真的动手。点取消、点框外的阴影、按 Esc，都是取消。

  • 要确认的：删链接、批量删除、删分类（连同子分类）、清空分类、清待办（含「清除已完成」）、删快照、恢复快照、导入备份、从云端拉回、清空全部数据、从歌单里移掉一首歌。
  • 顺手给一次撤销的：删单条链接、从固定栏拿掉、闲置链接搬去归档。
  • 不算删除、所以按钮不是红的：闲置归档（只是搬家，随时能搬回来）。
确认框的确定键默认是红色的（危险色）。看到红的，说明这一步删了就真没了；看到主色的，说明只是挪个地方。 另外，确认框是叠在别的弹窗上面的 —— 比如你在「分类管理」里点删除，确认框会浮在那个面板之上，取消之后分类管理还开着，不用重新打开一遍。
确认框开着的时候，单键快捷键不生效。不然你在确认「删不删」的时候随手按一下 R，背后的盲盒就抽出来了。

挪一条

  • 上下拖 = 在同一个分类里排序（只在「手动排序 + 当前分类没有子分类」时生效，这是为了保护数据，见下）。
  • 拖到左边的某个分类上松手 = 把这条链接搬进那个分类。拖的时候目标分类会高亮成靶心。
为什么拖动有时候「不动」：当这个分类下面还有子分类（比如「设计」下面有「设计/配色」）时，排序会被挡住 —— 因为列表里混着子分类的链接，按屏幕顺序写回去会把它们倒进父分类里。分类模式下更彻底一点： 中栏里混着所有分类的链接，所以那儿一律不给排序（否则一拖就把别家的链接倒进来）， 只留「拖到某个分类上松手 = 搬过去」这一条。想排序就先切到别的模式，或者把子分类收走。

04分类：分组与隐藏

建分类

  • 左栏分类标题右边那颗 ＋；
  • 或者工具条 分类 → 分类管理里新建 / 重命名 / 清空。

用「/」做层级，不用另建结构

分类名里带斜杠就是一层：写 设计/配色、设计/字体，页面上会自动出现一个「设计」分组，下面挂两个子分类。

设计 · 设计/配色 · 设计/字体 · 工作/周报

就地改名

双击分类名字直接改（回车提交，Esc 取消）。改父级的名字时，它下面的子分类会跟着一起搬，不会断掉。

一口气全部收起 / 全部展开

分类栏标题右边（＋ 的左边）那颗上下箭头：一下把所有分组折叠起来，再点一下全部展开 —— 连「最近添加」那棵树也一起算进去。箭头朝哪边，就是点下去的后果，鼠标停上去还会告诉你「全部折叠 / 全部展开」。哪些组是收着的会记住，下次打开还在。

分类后面的条数：默认不显示

每个分类名后面那个小数字，是这个分类里有多少条链接（连子分类一起数）。它默认不显示，想让它在哪就在这儿开：工具条 分类 → 分类管理弹窗最下面那组 「显示 / 不显示」 —— 两颗小按钮，点哪颗就是哪个状态，选中的那颗是实心填充（跟弹窗右下角那颗「完成」同一个颜色，深色主题下自动跟着变浅）—— 一眼看得出来现在是开还是关。开着还是关着会记住，下次打开还是你选的那个。

它是你自己的偏好，跟分类栏摆哪儿没关系 —— 分类栏挪到顶上、或者换成手机上那条横滑排，都照样听这个开关的。

在一个分类上点右键

分类也认右键，菜单里是这七件事：

打开这个分类等于点它一下
置顶这个分类把它挪到同一层的最前面，再点一次就取消置顶。置顶过的名字后面会多一颗小圆点。置顶一个父分类时，它的子分类会跟着一起上去（不然孩子会被落在原地，看着像迷路了）
重命名等于双击，就地改
新建子分类直接打开新建框，名字已经替你写好「父分类/」，接着打后半截就行
隐藏 / 让它重新出现整个分类（连同子分类）从所有地方收起来，随时能放回来
清空里面的链接分类留着，里面的链接清掉 —— 会先问一声，也会先自动存一份快照
删除这个分类连里面的链接和子分类一起删 —— 同样会先问一声、先存快照
「最近添加」和它下面那几档时间（今天 / 昨天 / 更早）不给右键菜单。它们不是真的分类，删了改都没地方落，所以在那儿点右键什么都不会发生（浏览器原本的菜单也不拦）。

两个特殊分类

  • 最近添加：按添加时间倒序，自动分「今天 / 昨天 / 更早」。它不落库、也不能拖。
  • 时间树：可以按时间维度看，同样自动分组。

把分类藏起来

在分类上点右键 → 隐藏这个分类，它就和它下面的子分类一起从所有地方消失：列表、搜索、快速查找、体检、统计里都看不到。数据一条不丢，只是不再露面。

想放回来：左栏分类树底下会出现一行「🔒 已隐藏 N 个分类 · 点这里管理」，点进分类管理里按「显示」就行；再在那个分类上点一次右键，菜单里那条也会变成「让它重新出现」。

别担心点不回来。就算把带子分类的父节点整个藏了，那一行提示也一直留着 —— 藏得再多也有回去的路。

05三种模式

工具条最左边那三个标签页：分类 / 全部 / 盲盒。选哪个会记住，下次打开还停在那儿。

分类按左栏顺序把所有分类连成一长条铺出来（每段一行分类名），最日常的模式 —— 想细看哪一类，左栏点一下，它自己滑过去。
全部三千条一口气摊开（分批渲染，不卡），配合筛选框当「全站搜索」用。
盲盒列表一条都不显示，台上只有一个礼物盒 + 一颗「抽一个」，抽到哪条开哪条。
盲盒的隐藏用法先用筛选框把池子缩小（比如「只看设计」），再抽 —— 抽签范围就跟着小了。盒子下面那行字会实时告诉你「筛完还剩几条、原本几条」。
固定链接栏三个标签页右边可以钉最多 5 个链接，点一下就开 —— 三种模式都显示，常去的那几个地方在哪儿都伸手够得到。点那颗 ＋ 从链接库里挑，钉满 5 个 ＋ 就自己收起来。在胶囊上点右键会出一个菜单：打开 / 改个名字 / 改链接 / 取消固定（改名字和改链接都是就地改，回车即存；取消固定带撤销）。一条都没钉的时候那里只剩一颗虚线 ＋，那就是入口。
场景（工作 / 生活…）筛选行上那颗 场景（在「排序」「标签」旁边）：把固定栏那一排和当前停在哪个分类存成一套，换场景时两样一起换过来。点它（或者在同一颗上点右键）出菜单：上面一行一个场景（右边标着「分类 · 几条」），下面是 更新成当前 / 新建场景… / 重命名… / 先不用场景 / 删除。切走时会把你刚调好的那套自动记回原来的场景，所以来回切不会丢东西。主题、强调色、隐藏分类这些不跟着场景走 —— 那是「你是谁」，不是「你现在在干嘛」。没启用场景时按钮上就写着「场景」两个字。

分类模式下：所有分类连成一长条

  • 铺开：中栏不再是「当前这一个分类」，而是从第一个分类到最后一个依次排开 —— 每个分类先一行分类名（右边标着这个分类能看见几条），下面紧接着它的链接。空分类（自己没链接、只当文件夹用的）不占位置。
  • 点左栏 = 滑过去：左栏点哪个分类，中栏就顺滑地滚到它那一段，那行分类名还会闪一下。不是「换一屏」，是「带你到那儿」。
  • 滚轮也会带着左栏走：你往下滚，左栏的高亮跟着换成当前这一段 —— 滚到哪一类，左栏就亮哪一类；滚到最底下时自动认最后一个分类。
  • 「最近添加」不跟着铺：它是按时间算出来的视图，不是真分类；点它还是自己一屏（今天 / 昨天 / 更早）。从它切回普通分类，铺开的那一长条会原样装回来。
  • 筛选的范围也跟着变了：分类模式下的筛选框现在是「在所有分类里筛」（以前是「在当前分类里筛」），输入框里的提示语会跟着变。筛到只剩一两个分类时，别的段会连着抬头一起消失。
  • 排序只改你正看着的那一段：铺开时每个分类各记各的排序方式，工具条那颗「排序」改的是左栏高亮的那一个分类（鼠标停在按钮上会告诉你）。
盲盒模式下按 R 就是「抽一个」；抽出来的那条，按 Enter 直接打开。

06搜索与筛选

搜索框（顶上那一条）

直接输网址比如 github.com，回车直接开，不走搜索引擎
输关键词用当前选中的那颗引擎搜
引擎名 + 空格 + 关键词比如 github 导航，就用 GitHub 搜「导航」，不用先切引擎
换引擎搜索框右边那排胶囊，点一下就切；也能自己加（在引擎设置里）
Enter在新标签页打开，不覆盖当前页面

快速查找（⌘K / CtrlK）

这是「在你自己那几千条链接里找」，跟上面的搜索框不是一回事。名字、拼音首字母、网址、标签都能搜，命中分类还能直接跳过去。

筛选框（列表上方那一条）

三种模式下都在工作。分类模式下中栏是所有分类连起来的长条，所以筛选是「在所有分类里筛」（筛到只剩一两个分类时，别的段连着抬头一起消失）；停在「最近添加」那一支时是「在最近添加里筛」；全部 / 盲盒模式下是「在全部链接里筛」。输入框里的占位提示会跟着模式变，一眼能看出在筛哪儿。

框里一有字，输入框右边缘就会冒出一颗 ✕，点一下把筛选清掉、列表当场恢复（不用等那半秒的防抖），光标还留在框里，接着打字就行。顶上那个搜索框也有同样的一颗 ✕。

盲盒模式下你没有列表可看，所以那个框到底在筛什么，页面会主动告诉你：输入框右边会多出一颗小胶囊，一开始写着「这个框先把池子筛小，再抽」，你一打关键词它就变成「已筛出 N 条，再点『抽一个』」；下面那行字也会跟着报「关键词「×」筛过之后，池子里还剩 N 条（原本 M 条）」。它不是摆设，它就是抽签范围。

旁边的 排序（手动 / 最常点 / 按名字）和 标签（按标签挑）也一样跟着当前视角走。想随机抽一条看，用工具条里那颗 随机（快捷键 R）—— 它和「抽一个」是同一个动作，只在盲盒模式里换个位置。

07右栏的几块

最常访问

按点击次数自动排的。你不点链接它就不会长东西；点得多的自己往上走，不用手动维护。（排到第几位看左边的序号就行 —— 行尾以前那个点击次数已经去掉了，它只是拿来排序用的，画出来反而让人不知道那是什么数。）

  • 右上 ＋ 可以手动加一条常用（比如天天要开的后台）。
  • 按住某一行直接上下拖，就能自己定顺序。拖过之后顺序就固定住了 —— 以后某个站点的点击数再怎么涨，也不会把排好的顺序冲乱。（拖动全程不会把文字选成一片蓝底：一按下就禁止选字，松手自动恢复。）
  • 行尾那颗小图钉是置顶 / 取消置顶，鼠标划过才出现。已经拖过顺序时，新置顶的会插到最前面。
  • 右上角的箭头可以展开 / 收起，收起状态会记住。

待办

就是个极简清单：输一句回车就加一条，勾掉就是完成，右上「清除已完成」一次清干净。放在导航页上，是为了「打开浏览器第一眼就看见」。

本地音乐

待办下面那个小盒子，纯粹给「一边整理链接一边听点东西」用的。歌都在你自己电脑上，不上传、不联网，断网也照放。

  • 加歌：点卡片右上角的 ＋ 选几首（mp3 / m4a / aac / flac / wav / ogg 这些常见格式都认）；或者直接把文件拖进卡片。一次选几首就一起进去。
  • 放：中间那颗实心圆按钮是播放 / 暂停，两边是上一首 / 下一首。最右边那颗换循环方式，点一下跳一种：顺序播放（放完最后一首就停）→ 单曲循环（这首反复放）→ 随机播放（下一首瞎挑一首）。当前是哪种，图标上写着。
  • 拖进度：上面那根细条就是进度，点哪跳哪，也能拖着走（鼠标划过卡片才现出那颗小圆点）。左下 / 右下写着「已放多久 / 总共多长」。最右边那颗是静音，旁边的小条调音量。
  • 歌单：点卡片右上角的歌单图标展开 —— 所有歌都在，正在放的那首会高亮，也能一首首删。加过歌之后卡片上会显示歌名。
  • 存哪了：歌本身存在浏览器的数据库里（IndexedDB，因为 localStorage 太小放不下音频），刷新、关掉再开都还在。但换个浏览器、换台电脑、清了浏览器数据就没了 —— 跟链接是一个道理，别把它当网盘。
  • 删歌只删这儿：移掉一首歌，或者「清掉整个歌单」，动的都只是页面里这份列表，你原来硬盘上的文件一个都没碰。
  • 不进备份：歌单和歌本身都不进备份文件，也不进快照（几百 MB 的音频塞进 JSON 会当场卡死），备份里只带音量、循环方式这几个小偏好。所以别拿备份当歌的保险柜 —— 歌的保险柜是你自己的硬盘。

最底下的那句话

右栏最底下躺着一句淡淡的文案（默认「先完成，再完美。」），点它就能改：可以只留一句放着不动，也可以写好几句，让它按天换或者按小时轮播。它和下面那排按钮是一小撮，永远贴在右栏最底部。

08批量整理三件套

一、导入（工具条的「导入」）

两种东西都能喂进去：

  • 纯文本：一行一条，名字 网址 或直接一个网址，分个类再导入。
  • 浏览器书签文件：Chrome / Edge / Safari 里「导出书签」得到的 .html 文件，拖进来即可，文件夹层级会变成分类。

二、链接体检（工具条的「体检」）

四个标签页挨个过一遍：

  • 重复：同一个网址被加了两次（自动归组，可一键去重）。
  • 闲置：很久没点过的死链，看着删；也可以一键搬去「归档」分类（只是搬家、按钮不是红的，右下角还给一次撤销，随时能搬回来）。
  • 整理：两类「该收拾一下」的 —— 空分类（一条链接都没有的）和名字没起好的（空的 / 名字直接就是网址或域名 / 超过 16 个字）。空分类能一条条留或删，也能一次全藏起来；名字那栏点「改」，会直接跳进正常的编辑框，并且替你预填一个短名字，你看着顺眼点保存就行。
  • 探活：真去请求一遍，把打不开的挑出来。
「整理」判空分类，算的是它自己加上下面所有子分类的条数。所以一个只用来分组的父分类（自己一条没放、孩子里有几条）不会被当成空的 —— 不然一删连孩子一起没了。 另外这一栏故意不跳过已经藏起来的分类：在分类管理里看得见、在体检里却看不见，那才叫奇怪。

三、导出为浏览器书签

备份 / 恢复 弹窗里那颗「导出为浏览器书签（.html）」—— 把你所有的分类和链接还原成一个书签文件，可以导进任何浏览器。想「上岸」的时候用这个。

四、管理台（标签栏的「管理」）

管理台的左边是一条通到底的侧栏：上面是站名，中间是「页面」（导航链接 / 首页 / 分享 / 文章），下面「工具」那一组就是平时散在各处的入口 —— 添加链接、导入、体检、分类、备份 / 恢复、云同步、写一条、写文章、首页、固定链接，一处就能点开，不用再跑回导航页。

表格里改一条链接是「就地改」的：点行尾那颗 ✎，这一行的分类 / 名字 / 网址三格当场变成输入框（分类是个下拉，改它等于整条搬家），改完按 Enter 或那颗 ✓ 存，按 Esc 或 × 放弃 —— 眼睛不用离开这一行，也不用先去右边再回来。

别的入口（添加链接、导入书签、备份 / 恢复、首页设置、写文章……）点开之后不弹居中的窗，而是占住中间那一整块地方：左边那条工具侧栏原地不动（想换一个工具，点一下左边那颗就切过去），右边是屏幕边，四边各留 12 的呼吸。宽是宽了，但面板里的东西不会跟着拉成一条 —— 内容收在 860 宽里居中放，屏幕再宽也是一行读得下去的字。Esc 先收面板，再按一次才回导航页。手机上就是四边各留 12 的整屏一张纸。

批量整理还有一张表格：点标签栏最右边那颗「管理」，就能看到所有分类的全部链接 —— 分类、名称、网址、点过几次、最后一次打开是什么时候、标签、有没有置顶（屏幕够宽时还会多一列「添加时间」）。链接多的时候表格按页翻，右下角可以选每页 50 / 100 / 500 / 全部。

  • 筛：上面那排能按分类、按状态筛（从未点击 / 30 天没打开 / 已置顶 / 重复网址 / 没标签），也能直接搜名字、网址、标签。
  • 勾：点任意一行就勾上，表头那个方框是「全选当前筛选结果」。
  • 批量改：勾完在顶上那一条里点「移动到…」「置顶」「取消置顶」「删除」。删除照样先问你一句，删前自动存一份快照。
  • 就地改：点行尾那颗 ✎ → 分类 / 名字 / 网址三格一起变成输入框，行尾换成 ✓ / × 两颗；Enter 或 ✓ 存，Esc 或 × 放弃。双击名字只改名字，双击网址只改网址 —— 各有各的快路。同一时刻只有一行能改：改着这行又去点那行的 ✎，上一行会还原并提示一句。
  • 换分类：就地改的时候那颗下拉里列着所有分类，选一个再存，这条链接就整条搬过去 —— 添加时间、标签、置顶都跟着走，不是复制一份。
  • 一条也不用先勾选：鼠标移到某一行，右边会冒出来四颗小按钮 —— 编辑 / 置顶 / 打开 / 删除；点网址本身就复制，复制完右下角会提示。
  • 导出 CSV：把当前筛选结果导成表格文件，Excel / Numbers 都能打开。

五、管理员：谁能改，谁只能看

导航页默认是只读的：任何人都能打开链接、复制网址、搜索筛选、换主题，但加、改、删、导入、恢复都会先弹一个密码框。第一次点「编辑」时会让你设一个管理员密码（至少 4 位）。

  • 解锁：点任意一个编辑入口 → 输密码；也可以在管理台右上角点「管理员登录」。
  • 锁定：管理台右上角点「锁定」，或者直接关掉浏览器 —— 解锁只在这一个会话里有效，重开就要重输。
  • 不用密码就能做的：打开链接、右键复制网址、搜索、按分类 / 标签筛、切主题和密度、导出备份和 CSV。
这道门只是「防手滑」，不是安全边界。这是一个纯静态的单文件页面，没有服务器 —— 懂技术的人清掉浏览器数据或改一下源码就能绕过，谁拿到这个文件都能看里面的链接。 真要做到「别人打不开、改不了」，得把页面放到服务器上，用登录 / 密码 / 访问控制来做。
另外密码只存在这台电脑的浏览器里（存的是加盐哈希，不是明文），不写进备份、不写进分享页。忘记密码无法找回 —— 清浏览器数据会把链接一起清掉，所以请先用「备份 / 恢复」导出一份。

六、发布到虚拟主机（让访客看到你的内容）

你在管理台里改的东西，只存在这台电脑的浏览器里。要让别人打开网址就看到这些内容，得「导出发布版」再上传：

  1. 管理台右上角点 「导出发布版」 → 浏览器下载一个 index.html（数据已经烘焙进文件，所以会比空壳大）。
  2. 把这份 index.html 传到你虚拟主机的网站根目录，覆盖原来那个。
  3. 打开网址验收：首页 / 导航 / 分享三个页面都应该显示你刚才的内容；底部没有「管理」，工具条上没有「编辑 / 导入 / 体检」。
发布版是一张快照，不是实时同步。以后每次改完都要再导出、再上传一次。
线上那份是只读的：没有后台入口，编辑和保存都被拦住，访客只能浏览和复制网址。
但文件本身谁都能下载查看 —— 里面的链接是公开的，别把私人网址放进去；真需要保密，得上服务器做登录。
管理台不是「另一份数据」 —— 它就是同一批链接换了个看的角度，改完立刻生效；点右上角「返回导航」或按 Esc 回到导航页，看到的就是改过的样子。 它不参与左右拖动切页：那三页是「用」的地方，管理台是「管」的地方。 另外点击数是从「在导航页点过几次」记下来的，按网址算 —— 两个不同名字指向同一个网址，它们共用同一份点击账。

11云同步（GitHub Gist）

想让手机上、公司电脑上看到同一份数据，用这个。原理是把你的数据存进一个你自己的私有 Gist，换设备时拉回来。

第一次怎么配

  1. 去 GitHub 生成一个 Token（Settings → Developer settings → Personal access tokens），权限只勾 gist 就够了。
  2. 打开 云同步，把 Token 粘进第一栏。Gist ID 留空。
  3. 点 上传到云端。成功后 Gist ID 和「Gist 地址」会自动填上。
  4. 换到另一台设备，粘同一个 Token，点 从云端拉回。

那三个字段默认是打码的

Token、Gist ID、Gist 地址默认都显示成 ••••••，防的是「有人站你背后一眼看全」。想核对内容就点状态条右边那颗 显示，三样一起露出来；再点一下又藏回去。

状态条在说什么

未连接还没填 Token，或者 Token 被清掉了
已连接Token 和 Gist ID 都在，可以点上传 / 拉回
只在本地Token 有了，但还没上传过 —— 这时「Gist 地址」是空的，「打开」那颗也不会出现
上次同步时间直接写在状态条上，不用猜
安全提醒：Token 只存在你自己这台浏览器的 localStorage 里，不会发给任何第三方；但它等于一把钥匙， 别在公用电脑上填。不想要了就点 清除 Token。

13放到虚拟主机 / 用域名访问（多用户）

这一节回答几个最常问的问题，包括：「我更新了页面，会不会把访客自己加的链接冲掉？」

先讲结论

不会。访客加的链接跟你的文件是两回事，互不干扰。

  • 链接存在访客自己浏览器的 localStorage 里，不在你的 HTML 文件里。
  • localStorage 是按域名隔离的 —— 每个访客打开你的域名，看到的都是他自己那份数据。
  • 你更新 index.html（加功能、改样式）只是换了「外壳」，访客已有的链接原封不动，刷新一下就是「新功能 + 他自己的数据」。
  • 反过来也成立：你本地的链接不会跑到访客那边去。

为什么能做到

因为整个页面是纯前端单文件：没有后端、没有数据库、不需要 PHP 或 Node。文件本身就是全部程序，数据全部留在浏览器。所以：

  • 上传：只要把 index.html 一个文件丢进网站根目录（或子目录）就行，静态空间就够。使用手册已经内置在这个页面里（右栏底下那颗「使用手册」），不用再传第二个文件。
  • 这一份 manual.html 是手册的源文件（方便单独编辑、也方便想把手册单独发出去的人），页面里那份是从它同步过来的，不传也不影响使用。
  • 不需要配任何环境、不需要建库、不需要开权限。
  • PWA 的清单文件是页面运行时生成的，不用另外上传。

访客会看到什么

  1. 第一次打开：看到你设的默认链接（就是文件里那批演示数据），他可以直接改、删、加。
  2. 他一旦改过，数据就落到他自己的浏览器里了。以后你换默认链接，他那边不会被覆盖 —— 他自己动过的那份说了算。
  3. 如果他一条都没动过，你换掉默认链接，他下次打开看到的就是你新设的那批。
想给别人一份「预置好的」链接？用 备份 / 恢复 → 导出备份 生成 JSON 发给他，他「导入备份」即可。 想让所有访客一进来就有你的那批链接，直接改 index.html 里默认数据那段（源码里的 DEFAULT_SITES）。

什么情况下数据会丢

清浏览器数据 / 重置浏览器会丢
换电脑、换浏览器看不到（数据不在那台机器上）
无痕 / 隐私窗口关掉就没了
你的域名 / 端口变了算成新站点，看不到旧数据

要跨设备、要防丢，就上云同步（第 11 节，存自己的私有 Gist），或者定期 导出备份。这两条路都是给访客自己用的，你不需要做任何额外配置。

做不到的事（先说清楚）

因为没后端，所以做不到「所有人共享同一份实时数据」：你在这台电脑加一条，别人那边不会冒出来。如果你需要的是这种「多人共用一张导航表」，那得配服务器和数据库，这个单文件方案不覆盖。

14数据存哪 / 常见问题

数据到底在哪儿

链接、点击次数、分类、待办、主题、密度、搜索引擎、隐藏分类、分享页「时光轨迹」里记的那些、首页那些文案和二维码，全部在这台浏览器的 localStorage 里，按 nav. 开头的键名存着。 本地音乐是唯一的例外：那里的歌存在浏览器的 IndexedDB 里（localStorage 只有 5MB，一首歌就塞不下），歌单也只记在你这台机器上。 没有任何一个字节发到服务器 —— 断网也能正常用。

15分享页 · 时光轨迹

一整页覆盖的视图，跟导航页共用同一套设计变量（所以换主题、换强调色它自动跟着变）。里面是一条竖着的时间轴：左边一条导轨（日期 + 一枚带柔光的圆点），右边摆卡片。一天一段，日期下面写着「周几 · 几条」。

怎么进去、怎么出来

  • 进：右栏页脚那一撮按钮里那颗 分享页；或者在地址栏后面直接加 #share —— 存成书签、发给别人都行（部署仍然只传 index.html 一个文件）。
  • 出：按 Esc，或者点底部标签栏那颗 导航。这里有个讲究：Esc 一次只退一层 —— 写东西的弹窗开着时，第一下只关弹窗，再按一下才离开这一页。

顶上那条搜索 / 筛选条

顶上那张卡跟导航页的搜索卡是同一张（同一个样式、同一套规矩），只是最右边那一格换成了固定链接。左边搜索框筛这一页：标题、正文、标签、域名里任意一处沾上这个词就留下。一整条都没沾上的那些天会连着日期一起消失，不会留个空日子在那儿；搜不到时给的是「没有匹配的记录」，不是「这一页还空着」。

搜索框右边那个数字：没搜的时候是「共 N 条」，搜了就变成「筛出 M / N 条」 —— 有搜索词时只报总数等于没说。

固定链接（最多 6 个）

  • 最右边那颗虚线 ＋：填个名字（不填就自动用域名），再填网址。网址只认 http(s) 开头；只填 example.com 会自动补成 https://。
  • 左键一点就开（新标签页）。在上面点右键能改名字 / 网址，或者删掉。最多放 6 个。
  • 它跟导航页顶上那条固定栏各存各的：那边是从你的链接库里钉出来的，这边是手填的独立网址 —— 所以在导航页删掉一个分类，不会把这里的链接连坐删掉。

写一条 / 改 / 删

  • 写一条：入口在管理台 —— 左边「工具」里的「写一条」，或者「分享页」页签右上角那颗（这一页平时只负责看；一条都还没有的时候，页码中间那颗「写第一条」也能开）。标题必填（空着不给保存），正文想写多少写多少（换行原样保留），链接和日期都选填，日期默认今天。
  • 改 / 删：鼠标压到某一条上，右下角才现出「编辑 / 删除」；手机上这两颗一直亮着（手机没有「悬停」这回事）。删除必问一句，删错了没有撤销。
  • 改了日期那条会搬到新的一天去 —— 日期是倒序排的，改得越新越靠上；把一天的最后一条删掉，那一整天会连着日期和圆点一起消失。

卡片能配图、能置顶、能标广告

写一条的弹窗里多了三个可选项，都是不填就当没有（老记录渲染出来跟以前一模一样）：

  • 封面图：填个图片网址，或者点右边的选图从本地挑一张（自动转成内嵌图，单张别超过 260 KB）。本地图选完，框里会显示成「已选本地图」一句人话（那串内嵌数据收在背后，不摊在框里）；想换成网址，直接在框里打字覆盖就行。它铺在标题上面，按 16:9 裁切，最高不超过 280px —— 一张宽卡不至于变成「一张图的附注」。
  • 置顶：打开之后这一条会被挑出来单独成一组，标题写着「置顶」，永远压在最上面 —— 不管它是哪天写的。标题前面还会挂一枚小图钉。
  • 标成广告：卡片会亮起来（边线用强调色、铺一层极淡的强调色底），并且带一枚「广告」徽标 —— 有封面图时浮在图的右上角，没图时落到最下面那一行，两种都一定看得见。

时间轴长什么样

左边那条导轨竖着走，日期一列排在最边上、每颗圆点正落在导轨上。右边是一片卡片，宽度用满整条内容列（内容区最宽约 1400px）。

分列按那一天写了几条来定：一条就自己占满这一片；两条一行两个、三条一行三个；四条会排成两行两个（一行三个会剩一张孤零零吊在最后，很难看，所以退成 2×2）；五条是「三 + 二」，六条是「三 + 三」。一句话：尽量别留单张的尾行。

不管那天有几条，卡片的右边都落在同一条竖线上，跟上面那条搜索卡也是同一条 —— 所以从 1 条、2 条、3 条的日子里一路扫下来，右边是齐的，不会「这条短一截」。

卡片本身有底色和细边，鼠标压上去边线会加深、浮起一层阴影。

长正文会先收起来

一条记录的正文超过 190 个字就先折起来（底下有渐隐），点它下面的 展开全文 才铺开 —— 不然一条能占满三屏，时间轴就没法翻了。

顶上那两行字可以改

大标题和它下面那行小字，点右边那颗 ✎ 就能改（默认「时光轨迹 / 时光总是悄然而逝，记录总是慢慢沉淀」）。

它跟着「外观」走

大标题、日期、条目小标题、那颗圆点用的是同一套强调色。想要参考图那种红 / 粉，去「外观」里挑一颗偏红的就行；浅色 / 深色也一起跟着变（深色下这几处的颜色是按深色底重新调过的，不会糊在黑底里）。

手机上长什么样

两栏并排太挤，所以日期挪到卡片上方竖着排，导轨压到最左边贴着屏幕边。顶上直接就是那张搜索卡：搜索框独占一行，固定链接再掉到下一行自己在里面横滑。卡片一律一列到底（手机上不再分列）；操作按钮常驻。

数据存在哪

记录在这台浏览器里，键名 nav.share.v1；顶上那几个固定链接是另一个键 nav.sharefix.v1。两个都会跟着备份和快照一起走，也会被「清空全部数据」一起清掉。导入一份老备份（还没有分享页 / 固定链接这两个字段的那种）不会把你的记录抹掉。

16底部标签栏（首页 / 导航 / 分享 / 文章）

屏幕底部正中那条浮着的小胶囊，就是标签栏。它把几个页面收进了同一个文件里切换 —— 首页、导航、分享、文章，点哪颗就去哪儿，当前那颗用强调色底标出来。

四个页面分别是什么

  • 首页：打开网站默认落在这一页。它是这个小站的「门面」：一句介绍、几块说明、两组二维码（见 17 首页能放什么）。
  • 导航：就是原来那个三栏首页 —— 链接、分类、搜索全在这儿。
  • 分享：分享页「时光轨迹」（见 15 分享页）。
  • 文章：用 Markdown 写长文的地方（见 18 文章页）。

自己加标签

  • 点最右边那颗 ＋：起个名字（最多 10 个字），再选点了去哪儿 —— 内置页面（首页 / 导航 / 分享 / 文章里挑一个）或者外部网址。 外链只认 http(s) 开头，点了会新开一个标签页（不在这个页面里跳走）。
  • 加多了会横向滚，不换行、也不会把页面撑宽。自己加的标签最多 12 个。

改名 / 改去向 / 删掉

  • 在自己加的标签上点右键：改名字 / 改去向、删掉这个标签。删除会先问一句。
  • 内置那四颗不给改也不给删（弄坏了回不来），右键会直接说一句，不会弹一个灰着的菜单。

左右拖动换页

  • 在页面上按住往左拖（手机上是往左划）＝ 去下一页，往右拖＝ 回上一页。顺序就是：首页 → 导航 → 分享。
  • 拖到一半能看见隔壁那一页跟着滑进来，松手拖过一小段就翻过去，没拖够就弹回原位。已经在头（首页）或尾（分享）还往那边拖，会有一点「拉不动」的手感。
  • 鼠标和手指都行。桌面上要拖得比手指远一些才算数 —— 免得选个文字就被换了页。
  • 竖着拖不算：那是在滚页面，照旧。点在能点的东西上（链接、按钮、输入框、标签栏、弹窗）也不会触发。
  • 手机上横向划分类条（导航页顶上那条）滑的是分类，不换页；分享页顶上那条固定链接也一样。
  • 只管上面这三页。文章页（第 18 节）和管理台不参与拖动 —— 它们各有各的入口，拖过去反而容易误触。自己加的标签也不在这个顺序里，有外链的话拖过去只会平白弹一个浏览器标签页。

地址栏上的锚

每一页各有一个锚：#home / #nav / #share / #post。想直接落在某一页，在网址后面加上它就行；刷新、存书签、发给别人都不会跑偏。什么都不加时看上次停在哪（存在 nav.view.v1）—— 第一次打开就是首页。

手机上

手机上标签栏一样贴在屏幕最底下，会自动避开 iPhone 那条横杠（安全区）；内容底部留了空，最后一行不会被它压住。首页那三张卡片在窄屏上改成竖着一列。

数据存在哪

自己加的标签存在 nav.tabs.v1 里，会跟着备份和快照走，也会被「清空全部数据」清掉（内置那四颗是写死在页面里的，永远在）。「上次停在哪个页面」不进备份 —— 换台电脑打开当然该从首页开始。

17首页能放什么

首页是打开网站第一眼看到的地方，内容区最宽约 1120px（比导航页窄一点，因为它是让人「读」的，不是让人「扫」的）。从上到下是这几块：

页面上一共五块

  • 首屏（电脑上是左右分栏）：左边是方块字（跟导航页的标志同步）+ 站名 + 一句介绍，下面两颗按钮「去导航页 / 看看时光轨迹」；右边是「这台设备上」 —— 链接、分类、时光记录、置顶四个数字，全是现算的真数（在导航页加一条、回到首页它自己就变了）。一条都还没有的时候，那句人话会换成「还没开始收东西」。
  • 这个站有什么：三张说明卡（各带一个图标），告诉你导航页、分享页、数据各是怎么回事（这三张是写死在页面里的）。
  • 关于：一段自我介绍 —— 这个站怎么来的、数据在哪、有什么脾气。它和「赞助」在电脑上是并排的两栏（每栏五百来像素，一行二十来字正好读），手机上才上下叠。
  • 赞助：一段想说的话；二维码在下面那一块。
  • 关注 / 找到我：两块二维码（默认是「公众号」和「交流群」），每块能配名字、图片、一句说明。

怎么改

  • 页脚那颗 编辑首页文案：弹窗里三个大框（介绍 / 关于 / 赞助），换行原样保留，各有字数上限（160 / 600 / 400 字）。
  • 下面两块二维码各有：名字（最多 12 字）、图片（填网址，或点 选图 从本地挑，单张 ≤ 260 KB；选完框里显示成「已选本地图」）、说明（最多 40 字）。
  • 还没放图的那块会显示成虚线占位，写着「去下面的『编辑首页文案』填」—— 一眼就知道是留着的位子，不是没做完。
  • 上面三张说明卡（「这个站有什么」）不给改，它们是固定的介绍。

数据存在哪

存在 nav.home.v1 里。它会进「导出备份」、但不进「自动快照」 —— 二维码的图片是内嵌的一长串数据，快照留 5 份很容易把浏览器的存储撑爆，而快照的用处是「链接 / 记录搞砸了能退回来」，首页文案不在那件事里（跟音乐一样待遇）。想留一份，导出备份带走就行。

手机上

首屏从左右分栏叠成一列（「这台设备上」落到两颗按钮下面，四个数字回到两行两列）；关于 / 赞助也改成上下叠；三张说明卡和两块二维码都改成竖着一列。

18文章页 · 用 Markdown 写长文

标签栏第 4 颗 文章。这一页是给「比自己记得住的那点事更长」的东西准备的：一篇笔记、一段折腾记录、一份给自己的说明。跟分享页那条「一句话记录」分工不同 —— 那个记瞬间，这个写完整的一篇。

列表：一眼看到写了哪些

  • 顶上一条搜索框：标题、正文、标签都能搜到；右边那颗 Esc 提示跟别处一样，有字的时候输入框里会冒出一颗 ✕（点一下清空、列表当场恢复）。
  • 搜索框右边写着 共 N 篇；筛起来之后变成 筛出 x / N 篇。手机上这行字先让位（屏幕太窄），搜索框留着。
  • 每张卡片：标题（最多两行）+ 摘要（最多两行）+ 日期 + 标签。标题和摘要都不会无限长，卡片高度才齐。
  • 顺序是「置顶优先，然后谁最近动过谁在前」。所以补完一篇半年前的笔记，它会自己浮上来 —— 不是按创建时间沉在底下。
  • 一篇都还没有时，中间那行写「还没有文章」并给一颗 写第一篇；搜不到时写「没有匹配的文章」，那颗按钮收起来（这会儿该换词，不是该写新的）。

读：点一下就进

  • 点卡片（或者键盘 Tab 到它、按 Enter）进阅读态。正文宽度收在 820，行高 1.85 —— 长文读起来不摇头。
  • 这是「同一页翻个面」，不换页也不刷新：地址栏还是 #post，按浏览器后退不会变成「退出文章页」。
  • 右上两颗：编辑 / 删除；左上 全部文章 回列表。Esc 也分层退：第一下回列表（还在这一页），第二下才离开文章页。
  • 长代码行自己在代码块里横着滚，宽表格也一样 —— 它们不会把整页撑宽。
  • 代码块顶上会标出语言（```js 写的那段就标 js），一眼知道这是什么；表格隔行浅底、引用左边一根强调色实条，长文里靠这些分层次。

写：在管理台中间那块编辑区里，写和预览两态

文章是内容，所以写和改都归后台（见 08 · 四、管理台）。在文章页点 写一篇 / 编辑，会把你带到管理台，编辑区就在中间铺开 —— 不再是一个盖在文章页上的大弹窗。管理台工具箱里那颗 写文章 也能直接开。

  • 点 写一篇（只读状态下第一次点会先要管理员密码，跟改链接是同一道门）。没解锁的人不会被顺路送进后台：先问密码，密码对了那一下才接着把编辑栏打开。
  • 它占住管理台中间那一整块（左边那条工具侧栏照样看得见、点得动），四边各留 12；别的表单内容收在 860 宽里，写文章这块更宽一档（980） —— 一行能多放十来个字，不会每二十个字折一次行。遮罩是透明的、不吃点击，所以想换个工具直接点左边那颗就行。手机上铺满整屏。
  • 四样东西：标题（必填，最多 60 字）、摘要（留空就自动从正文里挑第一段，去掉 # ** 这些标记）、标签（逗号分隔，最多 6 个）、正文（Markdown）。
  • 正文框吃掉剩下的高度：屏幕多高就能写多高，底下那颗 保存 永远贴着底边 —— 写长文不用一边敲一边滚。
  • 正文框右上角有 写 / 预览 两个小按钮。预览用的是同一个渲染器，所以「预览看到什么样，存下来就是什么样」；预览开着的时候继续打字，它跟着变。切到预览时那块地方整个交给预览，长文在框里自己滚。
  • 标题空着不让存（会提示一句，框还留在那儿让你填）。
  • 存完留在管理台 —— 一次连着写两篇的人不该被踹回前台。想立刻看效果，点提示条上那颗 去读，直接落到刚写那篇的阅读态。改一篇也一样，改完还在这儿。
  • 长文写到底不想找鼠标：⌘/Ctrl + Enter 直接保存。
  • 要关掉：右上角那颗 ✕、底下的 取消、或者按一下 Esc（只收这块编辑区，人还留在管理台）。

写的时候有哪些快捷键

正文框下面有一排小按钮 —— 点一下就等于按了一次对应的组合键，鼠标用户不用背键位；反过来，键位表就是这排按钮上的 title（鼠标停一下就能看到）。两边走的是同一套逻辑，不会出现「按钮好使、快捷键其实没这功能」。

⌘/Ctrl + B / I / `粗体 / 斜体 / 行内代码
⇧⌘ + X删除线
⌘/Ctrl + K链接：插成 [文字](地址)，光标直接落在地址里
⇧⌘ + K / H代码块 / 标题
⇧⌘ + . / 8 / 7引用 / 无序列表 / 有序列表（Windows 上是 Ctrl + Shift + 同一个键）
Tab / ⇧Tab缩进 / 退一格（每次两个空格；选了几行就整段一起挪）
⌘/Ctrl + Enter保存
Esc收起编辑区（人还在管理台）
  • 有选区就包住它；没选区就插一对空标记、并把中间那个占位词选中，接着敲字直接替换 —— 不用先删掉它。
  • 再按一次就是撤销：**粗体** 里再按 ⌘+B 会脱掉标记；标题、代码块同理（## 按一下变回正文，围栏按一下删掉，代码本身留着）。
  • 标题 / 引用 / 列表这类行首的快捷键，选了几行就逐行加；空行不动（夹一条空的「- 」行，渲染出来是一条空项目，很脏）。
  • Tab 只在确实要缩进的时候才接管（列表、引用、代码块里，或者行首已经有空格、你选了一段）。普通段落里按 Tab 还是照常把光标送到下一个框 —— 否则键盘就再也走不出正文框，连下面那颗「保存」都按不到。

**粗体** / *斜体* / ~~删除线~~下划线写法 _斜体_ 也认
`行内代码`里面的 * 是代码，不会被当成强调
``` 围栏代码块可以带语言名（```js），里面的尖括号原样显示

改 / 删

  • 读到某篇时右上角 编辑：同样把你带回管理台那块编辑区，里面带着旧内容，改完还是那一篇（不会又存出一篇新的）。
  • 删除会先问一句，并且先存一份快照：点错了能去「备份 / 恢复 → 自动快照」里挑「删文章前」那份退回来。

数据存在哪

全部在 nav.posts.v1 里，一篇一条。存的是你写的 Markdown 原文，不是渲染后的网页 —— 所以备份文件是能读的、以后换渲染方式也救得回来。

  • 它进「导出备份」也进「自动快照」（纯文字、份量小，很值得带上），「清空全部数据」会把它一起清掉。
  • 导出的发布版里也带着文章，但那是「给别人读」的一页：写 / 编辑 / 删除三颗一律不出现，就算绕过按钮也进不去。
  • 最多 200 篇，单篇正文最多 2 万字 —— 再多列表也没法看，浏览器的存储也扛不住。
