# 馨客栈 · 导航页（在线版）

**https://mackxin.github.io/xinkezhan/**

这个仓库只放**发布物**：一个 `index.html`（页面、样式、脚本、内置手册全在里面）和它的源文件 `manual.html`。
开发过程、测试套件与逐轮笔记留在私有仓库，这里保持干净。

页面的数据全部存在**你自己的浏览器**里（localStorage），这里只是那份代码；
所以打开就能用，也不会有人看到你收了什么。

- 部署：GitHub Pages（main 分支根目录）
- 更新：由开发仓库的 `tools/publish-pages.sh` 同步过来
